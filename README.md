# 🎮 Lele 游戏小站

精选益智解谜小游戏，点开即玩

## 🎯 在线游玩

[https://leleprogrammer.github.io/online-games](https://leleprogrammer.github.io/online-games)

## ⬇️ 游戏列表

| 游戏 | 说明 |
| --- | --- |
| Digital Klotski | 数字华容道，支持 3x3 ~ 12x12 16x16 20x20, WASD 或鼠标单击控制 |
| Sudoku | 数独，支持**简单、中等、困难、大师**四种难度, 键盘或鼠标单击控制 |
| Binairo | 黑白，支持**简单、中等、困难**三种难度, 支持 6x6 10x10 14x14 20x20 棋盘，键盘或鼠标单击控制 |
| Futoshiki | 不等式，支持**正常、困难**两种难度, 支持 4x4 6x6 8x8 9x9 棋盘，键盘或鼠标单击控制 |

## 🚀 本地运行

```bash
git clone https://github.com/LeleProgrammer/online-games.git
cd online-games
```

直接用浏览器打开 index.html 即可。
